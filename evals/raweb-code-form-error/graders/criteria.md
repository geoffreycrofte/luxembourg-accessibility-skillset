PASS if the code: gives the field a programmatically associated label; marks it required with a VISIBLE indication (not only the required or aria-required attribute); on error sets aria-invalid="true" and links the error message to the field (for example aria-describedby); and the error text names the problem. If the reply cites a RAWeb criterion for linking the error to its field, it must be 11.10 (Level A), not 11.11.
FAIL if any of these is missing, if the error relies on colour alone, or if the reply attributes error identification to 11.11 or calls it Level AA.
